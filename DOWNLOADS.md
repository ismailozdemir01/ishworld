# THE ISHWORLD Downloads

This is the **public distribution surface** for ISHWORLD.

Enterprise source code, internal tests, private integrations, build credentials and secrets are not distributed from this repository.

## v7.1.1

Validated release assets will be published here only after the private Enterprise CI pipeline completes its verification:

- Windows x64 executable
- Windows x64 installer
- Linux x64 executable
- SHA-256 checksums
- Release notes

No artifact is advertised as downloadable until it has been built and validated successfully.

## Release policy

The private Enterprise repository performs source verification, automated tests, native builds, installer install/health/uninstall checks and checksum generation. Only the resulting distribution artifacts are copied to this public repository's GitHub Release.

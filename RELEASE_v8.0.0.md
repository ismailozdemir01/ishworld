# ISHWORLD v8.0.0

**A World That Remembers.**

## Distribution

This is the public v8.0.0 distribution surface. Downloadable release artifacts are validated native binaries; proprietary Enterprise source is kept private.

## Release assets

- Windows x64 installer
- Windows x64 portable executable
- Linux x64 executable
- SHA-256 manifests

## Integrity

Verify the downloaded binary against the SHA-256 manifest published with the release before deployment.

## Security boundary

No credentials, private signing material, Enterprise source code or internal build material belongs in this public repository.

GitHub-generated source archives contain only the public distribution commit and therefore do not expose the private Enterprise source.

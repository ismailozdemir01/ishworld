## v8.0.0 — Public Distribution

ISHWORLD is distributed from this public repository as **validated native runtime binaries** for Windows x64 and Linux x64.

### Get the game

Open the latest **v8.0.0 GitHub Release** and choose your platform:

- Windows x64 Installer — recommended
- Windows x64 Portable EXE
- Linux x64 Native Binary
- SHA-256 verification manifests

## Source & security boundary

The proprietary Enterprise source code is **not part of this public repository**. Internal tests, private integrations, build systems, signing credentials and secrets remain in the private Enterprise repository.

GitHub automatically generates source-archive links for public release tags. Those archives contain only the files committed to this public distribution repository; they do not contain the proprietary Enterprise source.

## Release policy

A distribution is presented as validated only after the Enterprise release gate completes native builds, automated verification, platform smoke tests, installer checks and checksum generation.

Android/iOS packages are not advertised until real native platform builds and validation are available.

# THE ISHWORLD v8.0.0

**A World That Remembers. Your choices become history.**

## Public distribution

v8.0.0 is the current public distribution release for Windows x64 and Linux x64.

The release artifacts are produced by the private Enterprise release pipeline and published only after the required verification and native smoke gates pass.

## Included

- Windows x64 portable executable
- Windows x64 installer
- Linux x64 native executable
- SHA-256 integrity manifests

## Distribution boundary

The public repository contains player-facing distribution material only. Proprietary Enterprise source code, internal tests, private integrations, build credentials and secrets remain private.

GitHub's automatic release source archives reflect this public distribution commit only; they do not expose the private Enterprise source.

## Platform status

Android/iOS native packages are not claimed as released until real platform builds and validation are completed.
